# 그림

시험지 그림은 Claude가 직접 그리지 않는다. 순서:

1. **원본 재활용** — 교과서·학습지·기출 PDF에서 잘라 쓴다.
   ```
   python crop.py page 교과서.pdf 132 쪽132.png            # 쪽을 그림으로 떠서 자를 곳을 본다
   python crop.py crop 교과서.pdf 132 0.08 0.30 0.55 0.62 그림/Q03_1.png   # 비율 좌표(왼쪽 위 → 오른쪽 아래)
   python crop.py imgs 교과서.pdf 132 그림/추출                # 쪽에 박힌 그림 파일을 그대로 꺼내기
   python crop.py gray 그림/Q03_1.png 그림/Q03_1.png          # 흑백
   ```
2. **GPT 그림 생성** — 원본이 없거나, 원본을 시험지용 흑백 선화로 바꿔야 할 때.
   ```
   python gpt_image.py "광학 현미경으로 관찰한 양파 표피 세포, 세포벽과 핵이 보이게, 라벨 없음" 그림/Q05_1.png
   python gpt_image.py "첨부 그림을 시험지용 흑백 선화로, 설명 화살표·배경 지움" 그림/Q07_1.png --ref 원본.png
   ```
   한 장에 1~2분 걸린다. 만든 뒤 반드시 그림을 열어 과학적으로 맞는지·글자가 규칙에 맞는지 본다.

그림 규칙: 흑백, 그림 안 설명 문장 금지, (가)(나) 장면은 그림을 따로, 수치+단위는 정자·붙여 씀(3m, 60kg), 물리량 기호는 기울임, 첨자는 정자.

> 새 그림·고치기·교과서/기출 그림 바꾸기는 **5E 그림 엔진 플러그인 `5e-figure`** 를 먼저 쓴다(https://github.com/seungyeon980808-pixel/5e-figure, exam-maker 설치 스크립트가 같이 깐다). `gpt_image.py`는 그 엔진이 없을 때의 대체 도구다.
