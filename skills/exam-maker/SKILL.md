# exam-maker — 정기고사 함께 출제하기

선생님과 대화하며 시험 한 세트를 만든다. 끝난 모습: 선생님이 확정한 **v1.0 시험지(hwpx)·정답표(hwpx)·정답과 해설(PDF)·문항 검토 용지(PDF)** 가 선생님이 정한 폴더에 있다.

## 지킬 것 (먼저 읽기)

1. **모든 대화·보고·질문은 한국어**로 쓴다. 쉬운 말로, 짧게.
2. **시험 보안**: 시험 문항·학교 양식·교과서 파일은 이 컴퓨터의 작업 폴더에만 둔다. GitHub·공유 드라이브·외부 사이트에 올리지 않는다. 이 스킬 저장소 안에 시험 파일을 만들지 않는다.
3. **Claude는 그림을 직접 그리지 않는다**(SVG·코드 도형·matplotlib 금지). 순서: ① 교과서·학습지·기출 원본 그림 잘라 쓰기 → ② **5E 그림 엔진**(`5e-figure` 플러그인: 기출 그림 2만 장 참고 → GPT) → ③ 엔진이 없을 때만 `scripts/figure/gpt_image.py`. 글로 된 표는 그림이 아니므로 직접 만든다.
4. **선생님이 「고치지 말고 상의」라고 하면** 아무것도 고치지 않고 의논만 한다. 무엇을 바꿀지 말한 것만으로는 시작 지시가 아니다. 「고쳐」「반영해」「시작해」가 있을 때 고친다.
5. **적용 전 비교 시안**: 문항을 고칠 때는 먼저 「이전 판 | 바뀐 판」 비교 시안(`make_board.py --prev`)을 보여 주고 승인받는다.
6. **판 올리기**: 고칠 때마다 마이너 판을 올린다(v0.1 → v0.2 …). 평가계에 낼 수준이 되면 v1.0. **옛 판은 지우지 않는다**(`판/` 폴더에 쌓는다). 지울 일이 있으면 휴지통으로만 옮기고 영구 삭제하지 않는다.
7. 한글 시험지는 **내용이 확정된 뒤 마지막에 한 번** 만든다. 그 전에는 시안(HTML)으로만 고친다.
8. 보고할 때 만든 파일의 **전체 경로**를 적는다.

## 0. 처음 한 번: 설치 확인

`python <스킬 폴더>/scripts/doctor.py` 를 실행해 빠진 것을 확인한다. 빠진 것이 있으면 `references/설치-windows.md` 대로 설치를 도와준다(명령은 선생님 승인 뒤 실행).
교육과정 MCP(`curriculum-kr-secondary`)는 플러그인에 들어 있어 자동으로 연결된다. 도구 목록에 안 보이면 Claude 앱을 다시 시작하게 안내한다.

## 1. 문항을 만들기 전에 꼭 물어볼 것

답을 듣기 전에는 문항을 만들지 않는다. 한 번에 묶어서 묻고, 모르는 것은 「미정」으로 둔다.
- 학교 이름, 학년·학기·시험(중간/기말), 과목·시험 범위(단원 → 성취기준은 MCP로 찾아 확인받기)
- 문항 수, 배점(문항별), 총점, 선택형/서술형 개수, 서술형 부분 점수, 난이도 비율
- **학교 시험지 양식** hwp/hwpx 파일 위치(없으면 기본 양식), 모든 문단 줄 간격(%)
- 교과서(출판사·쪽 범위)와 학생들이 배운 **학습지·PPT·자료 위치**, 꼭 넣거나 뺄 내용
- 마감(평가계 제출일), 최종 파일을 둘 폴더, 파일 이름 규칙

## 2. 작업 폴더

선생님이 정한 곳, 없으면 `문서\출제작업\YYYY-MM-DD_학교_과목_시험\` (맥은 `~/Documents/출제작업/…`):
```
자료/     교과서.txt(본문 글), 교과서 PDF, 학습지, 학교 양식 (원본은 고치지 않음)
exam.json 문항 원본 — 모든 결과물을 여기서 만든다 (형식: references/exam-json.md)
판/       exam_v0.1.json, exam_v0.2.json … (옛 판 보관)
그림/     Q03_1.png … (원본 잘라낸 것·GPT가 만든 것)
시안/     코멘트판 index.html, comments_<판>.json
검사/v0.2/ 격리 풀이 세트·결과·요약.md
한글/     시험지·정답표 hwpx, 쪽 그림 확인
해설/     정답과 해설·검토 용지·점검표 PDF
```

## 3. 출제 흐름

### ① 자료 읽기
- 교과서 PDF가 있으면 본문 글을 `자료/교과서.txt`로 뽑는다(쪽 표시 포함). 학습지도 글로 뽑아 읽는다.
- 성취기준: MCP `search_standards`·`get_standard`로 찾고, 성취기준 해설·적용 시 고려 사항은 원문에서 자른다:
  `python scripts/curriculum/cut_curriculum.py 생명과학 자료/교육과정.txt --grep 핵형,염색체`
  (과목: 과학(중학교), 통합과학, 과학탐구실험, 물리학, 화학, 생명과학, 지구과학, 진로·융합 선택 과목 전부)

### ② 출제 계획표
문항마다 번호·성취기준·단원·난이도·배점·유형(〈보기〉/선지/서술형)·출처(교과서 쪽, 학습지)·그림 필요 여부를 표로 만들어 승인받는다. 정답 번호가 한쪽에 몰리지 않게 계획한다.

### ③ 문항 쓰기 → exam.json
- 학교 정기고사 문체: 「그림은 …을 나타낸 것이다.」「이에 대한 설명으로 옳은 것만을 〈보기〉에서 있는 대로 고른 것은?」「옳지 <u>않은</u> 것은?」 문장 끝은 마침표(쉼표 금지), 배점은 끝에 `[3점]`.
- 선지 5개, 〈보기〉 조합 선지는 ㄱ, ㄴ, ㄷ 조합 5개. 오답도 그럴듯하게, 선지끼리의 관계로 정답이 추론되지 않게.
- 교과서에 있는 용어·수치만 쓴다. 해설(`sol`)은 출제 의도·출제 근거(성취기준+교과서 쪽)·핵심 개념·선지별(또는 〈보기〉별) 해설을 같이 쓴다.

### ④ 시안(코멘트판) 보여 주기
```
python scripts/board/make_board.py 작업폴더/exam.json                       # → 시안/index.html
python scripts/board/make_board.py exam.json --prev 판/exam_v0.1.json      # 비교 시안(바뀐 곳 노란 칠)
node scripts/board/comment_server.cjs 작업폴더/시안 8883                    # 백그라운드로 실행
```
그다음 브라우저로 `http://127.0.0.1:8883` 을 연다(윈도우 `start http://127.0.0.1:8883`, 맥 `open …`).
선생님은 문항 옆 칸(전체·발문·자료·보기·선지·해설·그림)에 코멘트를 적는다 → 자동 저장 → `시안/comments_<판>.json`을 Claude가 직접 읽는다. 서버 없이 열었으면 「코멘트 전체 복사」 단추로 붙여 넣게 한다.

### ⑤ 코멘트 반영 → 판 올리기
코멘트마다 어떻게 고칠지 짧게 정리해 보여 주고, 승인되면 `판/`에 이전 판을 복사해 두고 exam.json을 고친 뒤 `meta.version`을 올린다. 비교 시안으로 다시 보여 준다. 이 ④⑤를 선생님이 만족할 때까지 되풀이한다.

### ⑥ 그림
`5e-figure` 플러그인(설치 스크립트가 같이 깐다)의 명령을 쓴다. 폴더: 윈도우 `%USERPROFILE%\.claude\plugins\marketplaces\5e-figure`, 맥 `~/.claude/plugins/marketplaces/5e-figure` → 아래에서 `<F>`.
1. **원본 재활용**: `python scripts/figure/crop.py page 교과서.pdf 132 쪽.png` 로 쪽을 보고 → `crop` 으로 비율 좌표 잘라내기.
   - 잘라 낸 교과서 그림은 글자 없는 시험지 그림으로 바꾼다: `node <F>/figure.mjs convert 잘라낸.png --kind textbook --out 그림/Q03` (기출 그림이면 `--kind exam`).
   - `result.json`의 `check.differences`(원본과 다를 수 있는 곳)가 있으면 원본과 나란히 보여 주고 알린다.
2. **원본이 없으면 새로 그리기**: `node <F>/figure.mjs make "요청" --subject 생명과학 --out 그림/Q05` — 기출 그림 색인에서 참고 그림을 골라 그린다. 요청 글 쓰는 법은 5e-figure 스킬을 따른다((가)(나)는 그림에 넣지 않고, 장면이 여럿이면 따로).
3. **고치기**: 코멘트판 「그림」 칸 코멘트는 `node <F>/figure.mjs edit 그림/Q05/fig-1.png "고칠 것" --request "원래 요청" --out 그림/Q05_v2` 로 반영한다.
4. 한 장에 보통 1분 안팎 → 여러 장은 2장씩 백그라운드로. 만든 그림은 반드시 열어 보고(Read) 과학적으로 맞는지·글자 규칙(수치+단위 정자, 기호 기울임)을 확인한 뒤 시안에 넣는다.
5. `5e-figure`가 없으면(설치 전) `python scripts/figure/gpt_image.py "요청" 그림/Q03_1.png [--ref 원본.png]` 로 대신한다.

### ⑦ 판마다 격리 검사 (정답 유일성·출제 오류·범위)
```
python scripts/check/make_check_set.py exam.json 검사/v0.2 --textbook 자료/교과서.txt --curriculum 자료/교육과정.txt --level "고등학교 2학년"
python scripts/check/run_check.py 검사/v0.2 --kind 둘다          # GPT(codex) 몫 실행, Claude 몫은 할일 파일로
```
- **Claude 몫**: `검사/v0.2/결과/claude_할일_<종류>_Qnn.txt` 마다 **하위 에이전트를 따로 하나씩** 띄운다(문항끼리·GPT 결과·exam.json을 못 보게). 에이전트에게 그 파일 내용 그대로 주고, 격리 세트 폴더만 읽게 하고, 답을 `결과/claude_<종류>_Qnn.md` 로 저장하게 한다. 메인 세션은 정답을 알려 주지 않는다.
- `python scripts/check/summarize.py exam.json 검사/v0.2` → 요약.md + review.json(코멘트판 「검토」 칸에 보임).
- 불일치·시비 「높음」·「교체 권장」은 근거를 읽고 선생님께 고칠 안과 함께 보고한다. 고친 뒤 다시 검사.

### ⑧ 한글 시험지·정답표 (내용 확정 뒤 한 번)
`scripts/hwpx/README.md` 를 따른다. 요약:
1. 학교 양식이 hwp면 한글 자동화로 hwpx로 바꾼다: `python scripts/hwpx/hangul_win.py to-hwpx 양식.hwp 양식.hwpx` (윈도우·한글 설치 필요, 처음 한 번 보안 승인 창).
2. `python scripts/hwpx/inspect_form.py 양식.hwpx` → `form_map.json` 초안을 보고 문항 번호·본문·〈보기〉·선지에 쓸 모양 번호를 확인·수정.
3. `python scripts/hwpx/build_exam.py exam.json 양식.hwpx 한글/시험지_v0.9.hwpx --map form_map.json`
   - 확정 모양: 〈보기〉 상자 머리 줄 얇게·안쪽 좌우·아래 여백 1.5mm, ㄱ·ㄴ·ㄷ 조합 선지 한 줄 5개, 모든 문단 줄 간격 = `meta.line_spacing`.
4. `python scripts/hwpx/hangul_win.py pages 한글/시험지_v0.9.hwpx 한글/쪽그림` → 쪽 그림을 열어 보고 넘침·겹침·쪽 나눔을 확인.
5. `python scripts/hwpx/build_answers.py exam.json 한글/정답표_v0.9.hwpx --form 양식.hwpx`
6. **마지막 조판은 한글에서**: `hangul_win.py open …` 으로 열어 선생님이 쪽 나눔·그림 크기를 손본다. 손본 파일을 다시 받으면 Claude는 그 파일을 기준으로 이어서 고친다(덮어쓰지 않고 새 판 이름으로).

### ⑨ 해설지·검토 용지
`python scripts/explain/make_explain.py exam.json 해설/` → 정답과 해설(선지별, 출제 의도·근거·핵심 개념), 문항 검토 용지. 격리 검사 결과로 `check.json`을 만들면 교과서·수준·교육과정 점검표도 나온다(`scripts/explain/README.md`).

### ⑩ v1.0 내기
모든 검사가 깨끗하고 선생님이 확정하면 `meta.version`을 v1.0으로 올려 시험지·정답표·해설·검토 용지를 다시 만들고, 선생님이 정한 최종 폴더에 아래 이름으로 저장한다.

## 파일 이름

`<연도>학년도 <학기>학기 <과목> <시험> <범위> <종류>_(<판>)_(<MMDD>).<확장자>`
예: `2026학년도 2학기 생명과학 기말고사 항상성 시험지_(v0.3)_(1121).hwpx`, `… 정답과 해설_(v1.0)_(1128).pdf`
종류: 시험지, 정답표, 정답과 해설, 문항 검토 용지, 점검표. 같은 판의 파일은 같은 판 번호를 단다.
