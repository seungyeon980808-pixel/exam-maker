# 문항 원본 `exam.json` 형식

시험 하나에 `exam.json` 하나다. 시안·코멘트판·격리 풀이지·한글 시험지·정답표·해설지·검토 용지를 **모두 이 파일 하나에서** 만든다.
고칠 때는 이 파일만 고치고 다시 만든다. 판을 올릴 때는 `판/exam_v0.2.json`처럼 사본을 남긴다.

```json
{
  "meta": {
    "school": "○○고등학교",
    "year": 2026, "semester": 2, "grade": 2,
    "exam": "기말고사",
    "subject": "생명과학",
    "title": "2026학년도 2학기 2학년 생명과학 기말고사",
    "version": "v0.1",
    "date": "2026-11-21",
    "line_spacing": 160,
    "textbook": "○○출판사 생명과학 (쪽: 120~180)",
    "form": "양식/학교양식.hwpx"
  },
  "items": [ { …문항… } ]
}
```

## 문항

| 칸 | 뜻 | 예 |
|---|---|---|
| `no` | 문항 번호 | `1` |
| `kind` | `"선택형"` 또는 `"서술형"` | |
| `pts` | 배점(소수 가능) | `3.5` |
| `unit` | 단원 | `"항상성"` |
| `standard` | 성취기준 코드 | `"[12생과02-03]"` |
| `level` | 난이도 `하`·`중`·`상` | |
| `ans` | 선택형 정답 `①`~`⑤`, 서술형은 모범 답안 | |
| `stem` | 발문 앞 글(상황·자료 소개) | `"그림은 … 나타낸 것이다."` |
| `blocks` | 자료 묶음(아래) | |
| `ask` | 묻는 문장(없으면 `stem`이 묻는 문장) | `"이에 대한 설명으로 옳은 것만을 〈보기〉에서 있는 대로 고른 것은?"` |
| `bogi` | 〈보기〉 문장들(ㄱ·ㄴ·ㄷ…) | `["…", "…", "…"]` |
| `choices` | 선지 5개(서술형은 빈 배열) | `["ㄱ", "ㄴ", "ㄱ, ㄷ", "ㄴ, ㄷ", "ㄱ, ㄴ, ㄷ"]` |
| `sol` | 해설(아래) | |
| `src` | 내용 출처: 교과서 쪽·학습지·기출 | `"교과서 132쪽 그림 3, 학습지 4"` |
| `rubric` | 서술형 채점 기준 `[{"점수": 2, "기준": "…"}]` | |

### `blocks` 종류

| `type` | 칸 | 뜻 |
|---|---|---|
| `text` | `text` | 문단 하나 |
| `fig` | `src`, `width`(단 폭 대비 0~1), `caption` | 그림. `src`는 `exam.json` 기준 상대 경로 |
| `table` | `head`, `rows`, `caption` | 자료 표 |
| `box` | `blocks` | 테두리 상자(탐구 과정 등). 안에 다른 블록 |
| `talk` | `lines`: `[["학생 A", "…"], …]` | 대화 상자 |
| `eq` | `tex` | 가운데 수식 한 줄 |
| `pair` | `blocks`: 블록 2개 | 나란히 두 자료(그림+표, 그림+그림) |

### 글 안의 표시
- 기울임 `<i>m</i>`, 굵게 `<b>`, 밑줄 `<u>` (「옳지 <u>않은</u> 것은?」), 아래·위 첨자 `<sub>`·`<sup>`.
- 수식은 `$ … $` 안에 LaTeX 꼴: `$\frac{a}{b}$`, `$v_0$`, `$x^2$`, `$\times$`. 한글 시험지에서는 한글 수식으로 바뀐다.
- 기호 ㉠㉡㉢, (가)(나)(다), Ⅰ Ⅱ는 그대로 쓴다.

### `sol` (해설)

```json
"sol": {
  "intent": "출제 의도 한두 문장",
  "basis": "출제 근거: 성취기준 + 교과서 쪽",
  "concept": "핵심 개념",
  "choices": ["① …(옳음/옳지 않음, 까닭)", "② …", "③ …", "④ …", "⑤ …"],
  "bogi": ["ㄱ(참) …", "ㄴ(거짓) …", "ㄷ(참) …"]
}
```
〈보기〉 문항은 `bogi` 해설을, 선지형 문항은 `choices` 해설을 쓴다. 둘 다 써도 된다.

## 검사 결과 `review.json` (선택)
격리 풀이 결과를 `{"1": {"GPT": "③ 일치", "Claude": "③ 일치", "시비": "없음"}}` 꼴로 두면 시안 오른쪽 칸에 같이 보인다.
